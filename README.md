**Інтерактивний віртуальний симулятор монтажу та тестування кабелю вита пара**  
Спеціально розроблено для курсу **«Комп'ютерні системи та мережі» (КСМ)**, Лабораторна робота № 1.

## 🚀 Як відкрити локально:
Просто двічі клацніть на файл index.html у вашому браузері (Chrome, Edge, Firefox, Opera).  
Додаток працює на 100% автономно, без інтернету, без сторонніх бібліотек та серверів.

j45-crimp-sim).
2. Завантажте всі файли з цієї папки до репозиторію:

## 💡 Функціонал симулятора:
* **Монтаж розпіновки:** вибір стандартів T568B (прямий кабель) та T568A.
* **Автентичні кольори:** реалістична текстура смугастих та однотонних жил витої пари з оголеними мідними кінчиками.
* **Механіка конектора 8P8C:** інтерактивні позолочені контакти-ножі, затискач оболонки кабелю.
* **Анімація та звуки (Web Audio API):** синтезовані механічні звуки зачистки, клацання та тріскачки кримпера.
* **Віртуальний кабельний LAN-тестер:** послідовне сканування ліній 1..8 світлодіодами Master та Remote блоків, діагностика узгодженої швидкості (1000 Mbps Gigabit vs 100 Mbps Fast Ethernet).
* **Акт верифікації (Сертифікат для звіту):** автоматична генерація фінальної картки з ПІБ студента, групою, часом та цифровим хешем захисту від підробки скріншотів.
